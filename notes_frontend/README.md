# Note Keeper (Angular)

A modern, light-themed notes app with sidebar layout. Features:
- Create note
- Edit note
- Delete note
- List notes
- View note details

Design:
- Primary #1976d2
- Secondary #424242
- Accent #ffca28
- Sidebar + main content area layout

Data storage:
- Notes are persisted in browser localStorage.

Development:
- Start: `ng serve` (configured to port 3000 in angular.json)
- Build: `ng build`
- Test: `ng test`

Structure:
- src/app/layout: Sidebar layout component
- src/app/notes: Notes CRUD components and service
